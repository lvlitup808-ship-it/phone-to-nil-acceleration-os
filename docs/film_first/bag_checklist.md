# Bag checklist

- Two phones (backup)
- Tripod or a wall to brace against
- Painters tape for athlete ID labels
- Printed yard-line reference if the field is unmarked
- Printed capture guide (one per filmer)
- Consent forms (one per under-18 athlete) — signed before cleats
- Labeling protocol (one for the coach)
- Blank assignments sheet
- Pen

## Field saves

1. Consent before cleats.
2. Sun behind you, not the athlete.
3. Warm-up is take zero. It does not count.
4. Backup phone + cloud + laptop the same night.
5. Log rejects in the report, not in your head.
